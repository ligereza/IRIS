# IRIS

IRIS will be the local-first interactive portfolio application for artists
and cultural projects.

The repository is intentionally an empty product boundary for now. Its
implementation will be extracted conceptually from MAK only after MAK is
ordered and the source, algorithm, dependencies, and rights are audited. No
MAK artwork, archive, credential, declaration, or internal file is copied
here.

The target architecture is:

```text
local media + artist decisions
        -> portfolio graph
        -> optional agent suggestions
        -> artist-approved views and exports
```

IRIS owns the portfolio product; PUPILA and VIZZ may provide optional
capabilities but are not embedded implicitly.
